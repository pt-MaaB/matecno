Backups e Recovery

Protecção de dados
em múltiplas camadas

Um backup que não é testado não é um backup — é uma esperança. A Matecno implementa, monitoriza e testa regularmente os backups para garantir recuperação real quando é necessário.

📐

Estratégia 3-2-1

3 cópias dos dados, em 2 suportes diferentes, com 1 cópia offsite (cloud). O padrão ouro da protecção de dados.

⏰

Backups Automáticos

Backups diários, horários ou contínuos consoante a criticidade dos dados. Sem intervenção manual, sem falhas humanas.

🔒

Backups Imutáveis

Cópias que o ransomware não consegue encriptar ou apagar. Protecção mesmo em caso de ataque bem-sucedido.

🧪

Testes Regulares de Restauro

Verificação periódica de que os backups são efectivamente recuperáveis. Sem surpresas quando mais precisa.

📄

Plano de Disaster Recovery

Documentação detalhada do processo de recuperação — quem faz o quê, por que ordem, com que objectivos de tempo.

Objectivos de Recuperação

RPO — Perda máxima de dados até 1 hora
RTO — Tempo de recuperação 2–4 horas

Valores típicos para sistemas bem configurados. Definem-se objectivos específicos com cada cliente.

✅ O que verificamos nos seus backups

  • • Os backups estão realmente a correr?
  • • São testados regularmente?
  • • Têm cópia offsite (cloud)?
  • • São resistentes a ransomware?
  • • Existem para todos os sistemas críticos?
